## 32位正文编程对照

保持同一309252字节BIN、115200、1024字节块、303块和相同发送/日志工具，仅改变Flash正文编程粒度。

| 阶段 | 字节编程 | 对齐32位编程 |
| --- | ---: | ---: |
| 发头至DATA | 2.594秒 | 2.657秒 |
| DATA至最后ACK | 32.391秒 | 28.828秒 |
| 最后ACK至DONE | 0.344秒 | 0.312秒 |
| 总耗时 | 35.329秒 | 31.797秒 |

本轮耗时减少3.532秒，约10.0%；各一次实测，不是重复统计。主要变化集中在分块阶段。对齐且剩余不少于4字节时使用FLASH_ProgramWord，起始未对齐和尾部用FLASH_ProgramByte；字节移位组装word，不要求源指针对齐。写后读回、锁定、范围及CRC检查保留。

68个主机模型场景通过，包括新增36组目标偏移、未对齐源缓冲和短尾部检查。实板ACK/DONE及CRC正确，全量App读回等于BIN，Bootloader和描述头检查通过，天气时钟启动并有网络时间/天气输出，FreeRTOS计数增长、任务数4。本次未新增LCD目视验收；此BIN四字节对齐，非整word尾部仅由主机模型验证。
